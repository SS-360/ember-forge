# Ember Forge mark

Updated 26 October 2026 for the user-requested Ember Forge rename.

The ember represents a small, lasting source of useful work; the forge represents creating and refining reusable skills. An asymmetric flame in amber-red (`#B9471E`) holds a warm core (`#FFD19A`) on a charcoal tile. The mark follows the restrained Apple-inspired interface and uses editable SVG paths at header and favicon sizes.

## Assets

- `apps/web/public/ember-forge.svg`: charcoal app tile with the amber-red ember. Used in the header and favicon.
- `apps/web/public/ember-forge-symbol.svg`: standalone ember with a transparent background.
- `apps/web/public/ember-forge-lockup.svg`: icon and Ember Forge wordmark. Lettering uses the platform system font rather than embedded font outlines.
- `docs/design/legacy-brand-preview.jpg`: historical browser-rendered preview of the previous mark; not a preview of the new ember.

The visible adjacent brand name provides the header's accessible label; its image is decorative to avoid repeating the name. The old anvil and pocket marks are not used by the current interface. Existing screenshots remain historical captures rather than edited evidence of the renamed app.

Tagline: **Turn repeated work into reusable skills.**
